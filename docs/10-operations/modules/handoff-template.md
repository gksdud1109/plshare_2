# Handoff Template

다른 AI가 바로 이어받을 수 있게 아래 형식을 고정해서 사용한다.

```md
# Module Handoff

## Module
M[number]. [module name]

## Primary Agent
[agent name]

## Backup Agent
[agent name]

## Input
- [input file path]

## Output
- [output file path]

## Current Status
- [done]
- [in progress]
- [blocked]

## Decisions Already Fixed
- [decision 1]
- [decision 2]

## Do Not Change
- [boundary 1]
- [boundary 2]

## Done When
- [completion condition 1]
- [completion condition 2]
```
