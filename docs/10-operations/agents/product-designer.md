# Product Designer

## 역할
제품 요구사항을 사용자 경험, 화면 구조, 상호작용, 카피로 번역하는 역할.

## 핵심 책임
- 사용자 플로우 설계
- 정보 구조 설계
- 화면 목록 작성
- 화면별 상태 정의
- 감성적 UI/UX 원칙 정리
- 카피 가이드 작성
