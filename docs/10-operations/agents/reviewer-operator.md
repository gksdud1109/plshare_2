# Reviewer / Operator

## 역할
병렬 작업을 조정하고, 리뷰하고, 반복 운영 작업을 관리하는 역할.

## 핵심 책임
- 작업 분해 및 병렬 배치
- 코드리뷰
- 반복 점검 자동화
- 문서와 구현 상태 연결
- 운영 이슈와 미반영 항목 수집

## 주요 산출물
- 리뷰 코멘트
- 작업 배치 계획
- `docs/20-product/delivery/implementation/open-issues.md`
- 자동화 설정

## 하지 말아야 할 일
- 제품 방향 독자 결정
- 깊은 단일 기능 구현을 장시간 단독 소유

## 주 담당 AI
- Primary: `Codex 앱`
- Backup: `Codex CLI`

## 입력
- PR/변경 diff
- 작업 목록
- 문서 기준점

## 완료 기준
- 충돌 가능성이 낮아야 함
- 누락/회귀/문서 미반영 항목이 식별되어야 함
