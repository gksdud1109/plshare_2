# Agents

이 디렉터리는 역할 기반 에이전트의 페르소나, 책임, 입력/출력 형식, 대체 가능 범위를 정의한다.

원칙:
- 에이전트는 이름이 아니라 역할로 운영한다.
- 같은 역할은 다른 AI가 대체할 수 있도록 입력/출력 형식을 고정한다.
- 작업 요청은 반드시 이 문서들의 책임 범위 안에서 나눈다.
