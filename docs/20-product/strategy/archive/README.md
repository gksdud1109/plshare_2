# PRD Archive

이 폴더에는 더 이상 최신본이 아닌 이전 PRD 버전을 보관한다.

운영 규칙:
- 최신 PRD는 `docs/20-product/strategy/` 루트에 둔다.
- 새 버전을 만들기 전, 이전 최신본을 이 폴더로 이동한다.
- 파일명은 원래 버전명을 유지한다.

예시:
- 최신본 작성 전: `docs/20-product/strategy/prd-vX.Y.md`
- 새 버전 작성 시: `docs/20-product/strategy/archive/prd-vX.Y.md`로 이동
- 새 최신본 생성: `docs/20-product/strategy/prd-vZ.W.md`

목적:
- `docs/20-product/strategy/`를 열었을 때 최신 문서만 바로 보이게 한다.
- 이전 버전은 추적 가능하게 남긴다.
