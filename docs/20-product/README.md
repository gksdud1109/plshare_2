# Product

이 폴더에는 실제 제품 개발 흐름에 맞춘 문서를 둔다.

권장 소비 순서:
1. `strategy/`
2. `research/`
3. `requirements/`
4. `design/`
5. `data/`
6. `delivery/`

역할별 진입점:
- Product Owner: `strategy/`, `research/`, `requirements/`
- Product Designer: `design/`
- Frontend Engineer: `design/`, `delivery/`
- Backend Engineer: `data/`, `delivery/`
- Reviewer / Operator: `delivery/`

현재 핵심 문서:
- 최신 PRD: `strategy/prd-v0.2.md`
- 최신 시장 리서치: `research/market-research-v0.3.md`
- 최신 기능 요구사항: `requirements/functional-requirements-v0.2.md`
- 최신 비기능 요구사항: `requirements/non-functional-requirements-v0.2.md`
