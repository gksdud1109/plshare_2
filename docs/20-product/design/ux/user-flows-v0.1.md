# User Flows v0.1

## Core Loop: Spotify-to-Apple Bridge

이 시나리오는 Spotify에서 플레이리스트를 가져와, 감성 맥락을 입혀 'PA'로 저장하고, 이를 Apple Music으로 내보내는 전체 과정을 다룬다.

---

### Scenario 1. Spotify 플레이리스트 가져오기 (Import)

| Step | [시스템 입력] | [사용자 액션] | [시스템 피드백] |
| :--- | :--- | :--- | :--- |
| **Entry** | '가져오기' 버튼 활성화 | 가져오기 버튼 클릭 | Spotify 연동 방식 선택(URL 또는 OAuth) 팝업/페이지 노출 |
| **Input (Happy)** | 유효한 Spotify 플레이리스트 URL 입력 | '가져오기' 실행 버튼 클릭 | '가져오는 중...' 로딩 스피너 및 진행률(곡 수) 표시 |
| **Normalization** | Spotify API에서 받은 트랙 리스트 | (대기) | ISRC 매칭 진행 상태 및 '매칭 성공/실패' 요약 리포트 표시 |
| **Success** | 정규화된 트랙 원장(Ledger) 생성 완료 | '자산화 단계로 이동' 클릭 | PA 편집(Assetize) 화면으로 전환 |
| **Empty** | Spotify 연동 계정에 플레이리스트가 없음 | 목록 새로고침 시도 | "가져올 수 있는 플레이리스트가 없습니다" 메시지 및 URL 직접 입력 유도 |
| **Error** | 유효하지 않은 URL 또는 권한 만료 | URL 재입력 또는 재인증 시도 | "URL을 확인하거나 계정을 다시 연결해 주세요" 에러 메시지 노출 |

### Scenario 2. 플레이리스트 자산화 (Assetize)

| Step | [시스템 입력] | [사용자 액션] | [시스템 피드백] |
| :--- | :--- | :--- | :--- |
| **Entry** | 정규화된 트랙 리스트 및 기본 메타데이터 | 자산 편집 화면 진입 | 커버, 제목, 일기 등 편집 필드 노출 |
| **Edit (Happy)** | 텍스트, 이미지 파일 선택 | 제목 수정, 이미지 업로드, 일기 작성, 태그 선택 | 실시간 입력값 반영 및 '저장 중' 표시 (자동 저장) |
| **Proof Signal** | 타이핑 패턴 및 입력 시간 등 메타데이터 | (입력 행위 지속) | 백그라운드에서 인간 생성 신호 캡처 |
| **Success** | 모든 필수/선택 필드 입력 완료 | '자산 저장 완료' 버튼 클릭 | 저장 완료 알림 및 'PA 상세 카드' 화면 노출 |
| **Empty** | 가져온 곡 목록 외 입력값 없음 | '저장' 버튼 클릭 | "자산의 가치를 높이기 위해 최소 한 줄의 일기를 써보세요" 넛지 노출 |
| **Error** | 이미지 업로드 실패 또는 네트워크 오류 | 재업로드 시도 | "이미지 저장에 실패했습니다. 텍스트만 저장하시겠습니까?" 대안 제시 |

### Scenario 3. Apple Music으로 내보내기 (Export)

| Step | [시스템 입력] | [사용자 액션] | [시스템 피드백] |
| :--- | :--- | :--- | :--- |
| **Entry** | 저장된 PA 상세 페이지 | 'Apple Music으로 내보내기' 버튼 클릭 | Apple Music 계정 연동 상태 확인 및 내보내기 확인 팝업 |
| **Execution** | Apple Music API 전송 데이터 패키지 | '확인' 클릭 | '내보내는 중...' 진행 바 및 곡별 매칭 상태 실시간 표시 |
| **Success** | Apple Music 내 플레이리스트 생성 성공 | 'Apple Music에서 열기' 버튼 클릭 | Apple Music 앱으로 딥링크 연결 및 성공 축하 메시지 |
| **Partial Success** | 일부 트랙(ISRC 미보유) 내보내기 실패 | 결과 확인 | "N곡을 내보냈습니다. M곡은 매칭되지 않아 제외되었습니다" 상세 내역 표시 |
| **Error** | Apple Music API 할당량 초과 또는 인증 실패 | 재시도 또는 계정 재연결 | "현재 내보내기가 불가능합니다. 잠시 후 다시 시도해 주세요" 알림 |

### Scenario 4. 자산 상세 공유 (Share)

| Step | [시스템 입력] | [사용자 액션] | [시스템 피드백] |
| :--- | :--- | :--- | :--- |
| **Entry** | PA 상세 화면 | '공유하기' 버튼 클릭 | 공유 옵션(링크 복사, 이미지 공유) 노출 |
| **Action** | 생성된 고유 웹 URL | '링크 복사' 클릭 | "공유 링크가 클립보드에 복사되었습니다" 토스트 알림 |
| **Web View** | (외부 수신자) 링크 접속 | URL 접속 | 로그인 없이도 볼 수 있는 'Refined Web Detail' 페이지 렌더링 |
| **Consumption** | 상세 페이지 내 각 트랙 데이터 | 'Apple Music/Spotify에서 듣기' 클릭 | 수신자의 플랫폼에 맞춘 외부 앱 연결 (Deep link) |
