# Screen Specs v0.1

## Screen 1: Dashboard (Main Entry)
- **화면 목적:** 사용자 자산 목록 확인 및 가져오기 시작.
- **주 정보 블록과 우선순위:** 
  1. '가져오기' CTA (Top)
  2. 저장된 PA 목록 (Card-style grid)
  3. 최근 활동 알림
- **상호작용:** 카드 탭 시 상세 보기, '+' 탭 시 가져오기 시작.
- **상태:** 
  - `default`: 카드 그리드 노출.
  - `empty`: "아직 생성된 자산이 없습니다. Spotify에서 추억을 가져와 보세요" 넛지.
  - `loading`: 뼈대(Skeleton) UI.
- **성공 기준:** 사용자가 가져오기 버튼을 탭하여 다음 단계로 진입.

## Screen 2: Import & Normalization (Bridge)
- **화면 목적:** Spotify URL 입력 및 정규화 상태 실시간 피드백.
- **주 정보 블록과 우선순위:**
  1. URL 입력 필드
  2. 실시간 매칭 상태 (N/Total 트랙)
  3. 매칭 성공률 요약
- **상호작용:** URL 붙여넣기, '가져오기' 탭.
- **상태:**
  - `loading`: ISRC 매칭 중인 곡들이 리스트로 스크롤되며 처리됨.
  - `error`: 매칭 실패율 50% 이상 시 경고 메시지.
  - `success`: '자산화 단계로 이동' 버튼 활성화.
- **성공 기준:** 정규화된 트랙 세트가 확보됨.

## Screen 3: Assetize (Creation)
- **화면 목적:** 정규화된 목록에 인간의 맥락(일기, 사진)을 입힘.
- **주 정보 블록과 우선순위:**
  1. 커버 이미지 업로드 영역 (가장 큼)
  2. 제목 및 감정/상황 태그
  3. 일기/메모 필드 (여유 있는 텍스트 영역)
  4. 트랙 목록 (하단 고정)
- **상호작용:** 이미지 드래그앤드롭/업로드, 태그 탭, 텍스트 입력.
- **상태:**
  - `default`: 자동 완성된 제목 및 기본 커버 노출.
  - `success`: 저장 후 상세 카드로 전환.
- **접근성:** 이미지 대체 텍스트 입력 필드 제공.
- **성공 기준:** 텍스트와 이미지 메타데이터가 트랙 세트와 결합되어 저장됨.

## Screen 4: Asset Detail (The Card)
- **화면 목적:** 완성된 자산의 가치를 감상하고 공유/내보내기 실행.
- **주 정보 블록과 우선순위:**
  1. Asset Card (커버, 제목, 작성자, 태그가 결합된 디자인)
  2. 일기 본문 (Magazine-like layout)
  3. 트랙 목록 (아티스트와 제목만 깔끔하게 노출)
  4. 'Apple Music으로 내보내기' 고정 CTA
- **상호작용:** 스크롤 시 카드가 상단에 고정됨, 공유 버튼 탭.
- **상태:**
  - `default`: Luxury/Refined 정체성이 가장 극대화된 페이지.
- **성공 기준:** 사용자가 '내보내기' 또는 '공유' 액션 수행.

## Screen 5: Export Progress
- **화면 목적:** Apple Music으로의 데이터 전송 상태 확인.
- **주 정보 블록과 우선순위:**
  1. 전송 진행률 (%)
  2. 매칭 성공 트랙 실시간 체크표시
  3. 실패/누락 곡 안내
- **상태:**
  - `loading`: 전송 중 애니메이션.
  - `partial success`: 누락 곡 명단 표시 후 '나머지 열기' 제안.
  - `success`: 'Apple Music에서 확인하기' 딥링크 버튼 노출.
- **성공 기준:** Apple Music 앱 내에 플레이리스트가 생성됨.

## Screen 6: Web Public View
- **화면 목적:** 비회원이 공유 링크를 통해 자산을 감상.
- **주 정보 블록과 우선순위:**
  1. Asset Card
  2. 일기 본문
  3. 'Apple Music/Spotify에서 재생' 개별 트랙 버튼
- **상태:**
  - `default`: 앱과 동일한 디자인 감성을 유지하되, 재생 버튼은 외부 앱 연결로 동작.
- **성공 기준:** 수신자가 외부 앱에서 곡을 재생함.
